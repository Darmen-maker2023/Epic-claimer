# Epic Free Games Claimer

Приложение показывает текущие бесплатные игры Epic Games и помогает забрать их на нескольких аккаунтах Windows. В комплекте есть Android-приложение для просмотра раздач.

## Windows

1. Установите Python 3.10+.
2. Запустите `install.bat`, чтобы установить зависимости и Chromium для Playwright.
3. При первом запуске войдите в аккаунты через `python claimer.py login acc1` (повторите для нужных аккаунтов).
4. Запустите графический интерфейс файлом `EpicClaimer.exe` или `python gui.py`.

Чтобы собрать Windows-приложение, запустите `build.bat`.

Настройки хранятся в `config.json`. Начальный пример находится в `config.example.json`.

## Android

Установочный файл: [`dist/EpicClaimer-Android.apk`](dist/EpicClaimer-Android.apk).

Android-версия загружает список активных раздач и открывает страницу выбранной игры в браузере. Войдите в Epic Games и завершите оформление там. Автоматизация Playwright доступна только в Windows-приложении.

Сборка APK из исходников описана в [`android/README.md`](android/README.md); сценарий сборки — `build_android.ps1`.

## Локальные данные

Папка `profiles/` хранит браузерные сессии Epic и другие данные аккаунтов. Не публикуйте её. Локальные настройки, журналы, история и временные сборки исключены через `.gitignore`.
